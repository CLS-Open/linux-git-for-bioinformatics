# Datasets

**Every sequence file in this directory is SIMULATED.** They are not experimental
measurements, they do not come from an organism, and no biological conclusion may
be drawn from them. They exist so that every number in the lessons is exactly
reproducible, offline, on any machine.

| File | Records | Size | Format | Provenance |
|---|---|---|---|---|
| `sample/reads.fastq` | 200 reads × 60 bp | 34 KB | FASTQ (Phred+33) | generated by `scripts/make_sample_data.py`, seed 20261106 |
| `sample/proteins.fasta` | 12 sequences (40–120 aa) | 1.8 KB | FASTA | same script, seed 20261107 |
| `sample/contigs.fasta` | 3 contigs (47, 56, 120 bp) | 302 B | FASTA | same script (deterministic literals) |

## Regenerate

```bash
python scripts/make_sample_data.py
```

The generator is deterministic: the files are byte-identical on every platform.
If they are not, that is a bug — report it.

## Why not real data?

Real data would be better science and worse teaching, for three reasons:

1. **Size.** A single real FASTQ run is gigabytes; this repository is <1 MB so it
   clones on a slow connection and installs in a classroom in seconds.
2. **Licensing.** Real sequence archives carry data-use terms (some controlled-access);
   shipping them would create legal and ethical complications for a CC BY resource.
3. **Determinism.** Real files change; lesson numbers then drift, and drift is how
   teaching materials silently rot.

When you are ready for real data, Module 7 and repository #11 handle public
accessions with recorded licences and accession numbers.

## Metadata

Each dataset has a machine-readable record in `metadata/` validated by CI:

```yaml
# metadata/reads_fastq.yml
name: reads.fastq
generator: scripts/make_sample_data.py
seed: 20261106
sha256: <computed by CI>
synthetic: true
licence: CC-BY-4.0
contains_personal_data: false
```

CI fails if a shipped data file has no metadata entry, or if the recorded
`sha256` no longer matches the file — so the README cannot quietly become false.
