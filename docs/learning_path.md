## Self-check before starting

Answer without looking anything up (answers in [quiz](assessments/quiz-01-module1.md)):

1. What does `>` do to the target file before the command runs?
2. How many lines is one FASTQ record?
3. What is the file descriptor number for stderr?

Two out of three correct → start at Module 1 and move quickly. Fewer → start at Module 1 and do both practicals.

## After this repository

You will be able to run real analyses (Modules 7–8), but you will not yet know *what* to analyse. That is #4 and #11's job. The intended sequence is:

1. **#8 (this repo)** — survive the machine.
2. **#4 bioinformatics-foundations** — sequence to function, by implementing the algorithms.
3. **#11 genomics-and-ngs-analysis** — real data, real QC gates, real confounders.
4. **#15 advanced-bioinformatics-and-ai-research** — benchmark and audit published models.
